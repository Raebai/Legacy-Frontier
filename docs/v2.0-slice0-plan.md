# Slice 0 — Combat-Feel Toy — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the single load-bearing question of the whole v2.0 pivot — *is it fun to move, dash, and cast in one room?* — as a self-contained combat sandbox.

**Architecture:** A new, isolated combat sandbox (`scenes/combat/Arena.tscn`) set as the run scene. A top-down `Hero` (CharacterBody2D) moves via the existing `move_*` actions, dashes on `dash`, and auto-aim-casts a projectile `Spell` at the nearest `Enemy` on `cast`. Two enemy archetypes chase and die. A thin "juice" layer (screenshake, hit-stop, hit-flash, death burst, knockback) makes hits feel crunchy. **Zero coupling to the existing hub/memory code** (`Conversation`, `NPC`, `MemoryConsolidator`, etc.) — that merges in Slice 1.

**Tech Stack:** Godot 4.6, GDScript. Headless validation via `godot --headless`; pure-logic tests follow the existing `tools/*_test_*.gd` `SceneTree` pattern; feel is validated by human playtest checkpoints.

## Global Constraints

- **Engine:** Godot 4.6, `config/features=("4.6","Forward Plus")`. GDScript, tabs for indentation (match existing scripts).
- **Input via named actions only (D-011, mobile-first).** No raw `physical_keycode`/`KEY_*` in scripts. All input through `Input.is_action_*` on named actions. A virtual-joystick/touch layer is a later slice — do not build it here.
- **Isolation:** all Slice 0 code lives under `scripts/combat/` and `scenes/combat/`. Do **not** modify `Conversation.gd`, `NPC.gd`, `Player.gd`, `World.gd`, or the memory stack.
- **Branch:** `v2.0-tower` (already created off `main`). Commit frequently, one commit per task minimum.
- **Class-name cache trap (from Sessions 6/8/9):** after adding any new `class_name` script, run a headless `--import` before the next `editor-run`.
- **Feel over correctness:** acceptance for feel tasks is the maker's playtest verdict, not an assertion. Numbers in this plan (speeds, cooldowns) are *starting points to tune*, not spec.
- **Viewport:** 640×360 (`window/stretch/mode="viewport"`). Design visuals at this scale.

var _shake_amount: float = 0.0
const SHAKE_DECAY: float = 12.0


func _ready() -> void:
	add_to_group("combat_camera")

	_shake_amount = min(_shake_amount + amount, 24.0)


func _process(delta: float) -> void:
	if _shake_amount > 0.0:
		offset = Vector2(
			randf_range(-_shake_amount, _shake_amount),
			randf_range(-_shake_amount, _shake_amount)
		)
		_shake_amount = max(_shake_amount - SHAKE_DECAY * delta, 0.0)
	else:
		offset = Vector2.ZERO

Create `godot-project/scripts/combat/Hero.gd`:
```gdscript
extends CharacterBody2D
## Slice 0 combat protagonist (the mage). Move now; dash + cast added next.

signal health_changed(current: int, maximum: int)

const SPEED: float = 210.0

@export var max_hp: int = 100
var hp: int = 100
var facing: Vector2 = Vector2.RIGHT


func _ready() -> void:
	add_to_group("hero")
	hp = max_hp
	health_changed.emit(hp, max_hp)


func _physics_process(_delta: float) -> void:
	var direction: Vector2 = Input.get_vector(
		"move_left", "move_right", "move_up", "move_down"
	)
	if direction != Vector2.ZERO:
		facing = direction
	velocity = direction * SPEED
	move_and_slide()


func take_damage(amount: int) -> void:
	hp = max(hp - amount, 0)
	health_changed.emit(hp, max_hp)
	if hp == 0:
		_die()


func _die() -> void:
	# Slice 0: just reset to full so the feel loop never stops.
	hp = max_hp
	health_changed.emit(hp, max_hp)
```

- [ ] **Step 3: Write `Targeting.gd`**

Create `godot-project/scripts/combat/Targeting.gd`:
```gdscript
class_name Targeting
extends RefCounted
## Pure auto-aim helpers. No state; static functions only.


static func nearest(from: Vector2, targets: Array) -> Node2D:
	var best: Node2D = null
	var best_d: float = INF
	for t in targets:
		if not is_instance_valid(t):
			continue
		var d: float = from.distance_squared_to(t.global_position)
		if d < best_d:
			best_d = d
			best = t
	return best


static func aim_direction(from: Vector2, targets: Array, fallback: Vector2) -> Vector2:
	var target: Node2D = nearest(from, targets)
	if target == null:
		return fallback.normalized() if fallback != Vector2.ZERO else Vector2.RIGHT
	var dir: Vector2 = target.global_position - from
	return dir.normalized() if dir != Vector2.ZERO else fallback.normalized()
```

## A straight-flying auto-aimed projectile. Hits the first enemy, then frees.

const SPEED: float = 460.0
const LIFETIME: float = 1.4

@export var damage: int = 18
var _dir: Vector2 = Vector2.RIGHT

**Interfaces:**

- Produces: `Enemy` (CharacterBody2D, group `"enemy"`) with `@export var max_hp`, `@export var move_speed`, `@export var touch_damage`, `@export var tint: Color`.

- [ ] **Step 1: Write `Enemy.gd`**

Create `godot-project/scripts/combat/Enemy.gd`:
```gdscript
extends CharacterBody2D
## Slice 0 enemy: chases the hero, takes spell damage, damages on contact, dies.

@export var max_hp: int = 40
@export var move_speed: float = 95.0
@export var touch_damage: int = 12
@export var tint: Color = Color(0.9, 0.35, 0.3, 1)

var hp: int = 40
var _hero: Node2D = null
var _touch_cooldown: float = 0.0

@onready var _visual: ColorRect = $Visual


func _ready() -> void:
	add_to_group("enemy")
	hp = max_hp
	_visual.color = tint
	var heroes: Array = get_tree().get_nodes_in_group("hero")
	if not heroes.is_empty():
		_hero = heroes[0]


func _physics_process(delta: float) -> void:
	_touch_cooldown = max(_touch_cooldown - delta, 0.0)
	if not is_instance_valid(_hero):
		return
	var dir: Vector2 = (_hero.global_position - global_position).normalized()
	velocity = dir * move_speed
	move_and_slide()
	if global_position.distance_to(_hero.global_position) < 22.0 and _touch_cooldown <= 0.0:
		if _hero.has_method("take_damage"):
			_hero.take_damage(touch_damage)
			_touch_cooldown = 0.8


func take_damage(amount: int) -> void:
	hp = max(hp - amount, 0)
	_flash()
	if hp == 0:
		_die()


func _flash() -> void:
	_visual.color = Color.WHITE
	await get_tree().create_timer(0.06).timeout
	if is_instance_valid(self):
		_visual.color = tint


func _die() -> void:

class_name Juice
extends RefCounted
## Static game-feel helpers. Time-scale-safe so hit-stop restores itself.

# The active SceneTree is reachable via Engine's main loop.
static func _tree() -> SceneTree:
	return Engine.get_main_loop() as SceneTree


static func hit_stop(duration: float = 0.06) -> void:
	var tree: SceneTree = _tree()
	if tree == null:
		return
	Engine.time_scale = 0.05
	# ignore_time_scale = true so the restore timer runs in real time.
	var timer: SceneTreeTimer = tree.create_timer(duration, true, false, true)
	await timer.timeout
	Engine.time_scale = 1.0


static func shake_camera(amount: float = 6.0) -> void:
	var tree: SceneTree = _tree()
	if tree == null:
		return
	for cam in tree.get_nodes_in_group("combat_camera"):
		if cam.has_method("add_shake"):
			cam.add_shake(amount)
```
