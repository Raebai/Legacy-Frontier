## Controls
| Input | Action |
|---|---|
| WASD / arrows | Move |
| Space | Dash (burst + cooldown; dashes THROUGH enemies) |
| Left mouse | Cast auto-aimed spell (nearest enemy) |
| F / right mouse | Melee — alternates punch / kick (short-range arc, hit-frame-synced) |
| Q | GIANT blast — telegraph circle blooms, then big AoE detonation (2s cooldown) |
| walk over the sword on the floor | Equip it — swaps the stick figure's weapon + beefier melee |

## What to feel for (the USP is fighting feel)
- [ ] **Stick figures read as fighters.** Hero (blue, mage: hat+robe+staff) and enemies (bare sticks, tinted) animate: run cycles legs, dash leans, cast raises arms, punch/kick thrust, hurt recoils. Placeholder-procedural — does the MOTION read?
- [ ] **Melee is crunchy.** Punch/kick lands with hit-stop + screenshake + sound + **visible knockback** (enemy gets shoved ~27px and recovers). Does it feel like a hit connects?
- [ ] **The GIANT blast is spectacular.** Q → a danger circle blooms/fills over ~0.55s → detonation: particle burst + expanding shockwave ring + heavy shake + big sound + enemies flung (~64px). Is it a "cool" clippable moment? Bigger? Longer windup? More particles?
- [ ] **Dash-to-dodge feels snappy** (passes through enemy bodies — contact damage still applies by proximity).
- [ ] **Cast** still feels good alongside the new melee.
- [ ] **Weapon pickup** — grabbing the sword visibly changes the stick figure's hand + makes melee hit harder/reach further. Does gear-changes-you land?
- [ ] **Audio** — cast / spell-impact / enemy-death / hero-hurt / melee-swing / melee-hit / blast all fire (TomMusic pack). Right sounds? Too loud/quiet?
