# v2.0 Slice 2 — Playtest Checklist + GO/NO-GO

> Slice 2 turned the combat toy into a **loop**: a hub where two NPCs remember you, a tower you enter, floors you climb, and a return where the NPCs react to how the run went. Plus two playable classes and two new dodge-the-tell enemies.
>
> **Everything below was built + verified HEADLESS** (logic, wiring, no-crash, 15/15 test suites green). Feel, look, and "is the loop satisfying" need your hands. Numbers in _italics_ are current tuning values (dials, not spec) — a row that fails on *feel* points at the constant to change.
>
> Branch: `v2.0-tower`.

## Two entry points

| Launch | What you get | Use it for |
|---|---|---|
| **F5** (main scene = `Main.tscn`) | The **full loop**: hub → walk into the tower portal → floors → back to hub | Testing the loop + the NPC-remembers-your-run moat |

## A — The loop (F5)

- [ ] F5 launches into the **hub** (the two-room world with Raebai + Mirelle), not the arena.
- [ ] A warm **"ENTER THE TOWER"** portal pulses in the first room (south of your start). Chat still works (walk to an NPC, press E). _(World.gd TOWER_ENTRANCE_POSITION)_
- [ ] Walking into the portal loads the **arena on floor 1** with a "Floor 1 / 5 · surface" banner. _(GameState.enter_run)_
- [ ] Clearing every enemy on the floor opens a cyan **EXIT** portal; walking into it advances to floor 2 (banner updates, enemies repopulate). _(Arena._on_floor_cleared → GameState.advance_floor)_
- [ ] The floor **theme shifts** as you climb: surface (green) → underground (dim, floors 3–4) → sky (cold blue, floor 5). Subtle wash, readable. _(GameState.floor_theme_tint)_
- [ ] Enemies get **denser + tankier + more brutish** the deeper you go. _(GameState.floor_enemy_budget/concurrent_cap/brute_chance; Arena hp_mult)_
- [ ] **Clearing floor 5** (the guardian floor) ends the run and drops you back in the hub — victorious. _(advance_floor past TOTAL_FLOORS → end_run(false))_
- [ ] **Dying** in the tower ends the run and drops you back in the hub. _(Hero._die → GameState.end_run(true))_

## B — The moat: NPCs remember your run

This is the differentiator. After a run ends (win or death), you're back in the hub.

- [ ] Walk up to **Raebai** (E) right after a run. His **opening line references the run specifically** — the floor you reached, whether you died or cleared, maybe the element you used. Not a generic greeting. _(GameState.run_hint_text → Conversation callback addendum)_
- [ ] Walk up to **Mirelle** too — she also knows about the run (both hub NPCs are told). _(GameState.apply_run_to_hub_npcs iterates group "npc")_
- [ ] Do a **second run**, come back, re-engage: the NPC references the **latest** run (the old run fact was replaced, not stacked). _(merge_run_fact — one run fact, cap-obeying)_
- [ ] Quit and relaunch after a run; walk back to an NPC. They **still** know about the last run (it persisted to disk in their memory). _(ingest_run_fact → key_facts → save_memory)_
- [ ] The run reference feels **in character** (Raebai's unhurried witness voice; Mirelle's gossipy warmth), not like a stat readout. If it reads robotic, the run-fact/hint wording in `GameState` is the lever.

## C — Rogue class + live switch (Tab)

- [ ] Press **Tab**: the figure visibly changes (hood + sword instead of hat + staff) and plays differently. Press Tab again to switch back. _(Hero.configure_class)_
- [ ] **Rogue LMB** throws a faster, lighter blade (quicker cadence than the mage bolt). _(cast_cd 0.26, blade 11)_
- [ ] **Rogue dash (Space)** deals damage to enemies it passes *through* — dash into a cluster and they take hits + get knocked. Each enemy is hit once per dash. _(dash_strike 16, range 42)_
- [ ] **Rogue Q** is a self-centred whirlwind (reuses the nova), not the mage's targeted giant blast. _(aoe = nova)_
- [ ] **Rogue T (nova)** does nothing — it's mage-only. _(has_nova false)_
- [ ] **Mage still feels exactly as before** — bolt, giant blast, nova, staff. (Switching to mage should feel like no regression.)
- [ ] The two classes feel **genuinely different to play**, not reskins. Rogue = in-your-face; mage = zoner. If they blur, the rogue kit numbers are the lever.

## D — New enemies: dodge the tell

Alongside the chaser (orange, fast/weak) and brute (magenta, telegraphed heavy strike):

- [ ] **Caster** (indigo): keeps its **distance**, roots with a small charging tell, then fires a **bolt** at where you were. Moving/blinking sideways dodges it; standing still eats it. _(CASTER_RANGE 180–320, WINDUP 0.7; EnemyProjectile 16 dmg)_
- [ ] **Charger** (amber): locks a **lane** (a growing rectangle telegraph aimed at you), then **rockets** down it. Sidestep the lane to avoid; it hits once, hard. _(CHARGE_WINDUP 0.7, SPEED 520, DAMAGE 24)_
- [ ] Both tells are **readable and fair** — you can react if you're paying attention, but they punish standing still. Windup too short = cheap; too long = trivial. _(CASTER_WINDUP / CHARGE_WINDUP)_
- [ ] The four archetypes read **distinct at a glance** (colour + behaviour) and mix into interesting fights, not noise.

- [ ] Dash i-frames, input buffering, hit-stop/screenshake weighting, enemy death spectacle, blink, nova, destructible crates + scorch decals, element recolour, rank title + escalating aura — all still land. _(unchanged files; see `docs/v2.0-slice0-checklist.md` for the granular rows)_

## F — The verdict (GO/NO-GO)

Play the **full loop** (F5) at least twice — once as mage, once as rogue; die once, clear once. Then:

- [ ] **Is the loop satisfying?** Does "hub → climb → back to hub" have a rhythm, or does it feel like two disconnected screens bolted together?
- [ ] **Does the NPC-remembers-your-run moment land?** Was there a "wait, he actually knows what just happened to me" beat? That's the whole pitch.
- [ ] **Do the two classes justify the switch?** Would you replay to try the other one?
- [ ] **Do the new enemies add real decisions?** (kite the caster, sidestep the charger vs just facetank)
- [ ] **Is 15–30s of this clippable?** Climb + dodge-the-tell + class fantasy + "the town roasts your death" — does it read on a feed?

**Verdict:**

- **GO** → the loop + moat work. Next: guardian boss on floor 5, hub class-select UI, more run-outcome flavour into NPC memory.
- **NO-GO** → say which section broke (loop / moat / class / enemies / feel) and I tune from there before building more.

## Known non-goals (NOT failures)

- **Placeholders everywhere** — procedural stick figures + primitive-drawn portals/telegraphs/bolts/decals are stand-ins for real animated sprites + shader VFX (asset-gen pipeline later).
- **No hub class-select UI yet** — you pick class with Tab (debug). A proper hub choice comes later; `GameState.selected_class` already carries it.
- **Floor 5 is a dense wave, not a bespoke guardian boss** — `boss_killed` is wired and flips on clearing floor 5, but a real multi-phase guardian is a later slice.
- **Rank grants no combat stats** — still title + aura only.
- **Elements are cosmetic** — colour only, no damage types.
- **HP doesn't carry hub↔run** — hub Player and combat Hero are separate; entering a run is a fresh Hero at full HP by design (for now).
- **Run outcome is a single durable fact** — rich run history / consolidation into long-term memory happens through the existing pipeline over repeated mentions, not as a dedicated run log.
- **Numbers are untuned starting points.**
