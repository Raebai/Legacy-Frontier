## 1. The Ashspire Guardian (floor-5 boss)
Reach floor 5 (climb, or die-and-reclimb). Verified via GPU capture across all 3 phases.
- [ ] A **⚔ GUARDIAN ⚔** banner + a **THE ASHSPIRE GUARDIAN** name card + a top-screen **boss health bar** (3 segments = the 66/33 phase gates), with **boss music**.
- [ ] The boss is a **giant stone colossus** with glowing red eyes + a molten ember core + a red aura (offset from you so it reads as its own silhouette; the camera fits the whole arena).
- [ ] **P1** (100–66%): telegraphed ground-slam + rock pillars. **P2** (66–33%): enrage — summons adds + fires beams/rays. **P3** (33–0%): "ashfall" — meteor storm + a big convergence nuke + point-blank nova. Every attack is telegraphed (dodge the tell).
- [ ] Killing it conquers the tower (the existing clear→conquer path).
- **Feel tuning** (`Boss.gd` / `Encounter.gd`): `BOSS_BASE_HP`, `RIG_HEIGHT`, phase thresholds/cadence `PHASE_CD`, aura strengths. If the colossus ever washes bright, lower the `BossAdornment` core alphas or the aura strength.

## 2. Co-op (2–4 players, friendly fire ON)
### How to run it
- **Same machine (test):** open the game twice. Instance A → **Host Co-op**. Instance B → type A's IP (`127.0.0.1` locally) → **Join**. Back on A → **Start Run**. Both drop into the tower.
- **With friends:** the host forwards/【shares】 their IP:port (`24565`); friends Join it. (LAN or a VPN like Hamachi/Tailscale for now — no matchmaking server yet.)
- **Headless smoke test** (proves connection + spawn): `python-tools/coop_smoketest.sh` (or run two console instances with `-- --server` and `-- --client 127.0.0.1`). Expected `[NET]` lines: host sees a peer (total=2), and **both** print `heroes=2`.

### What to check
- [ ] Both players appear in the arena; **each drives only their own hero** (the other moves via sync).
- [ ] **Friendly fire:** your spells can damage your teammate (and vice versa). The caster is never self-hit.
- [ ] Your class is the one you picked in the lobby.

### VERIFIED (headless, loopback)
- Two instances connect over 127.0.0.1; host sees the peer.
- Both enter the arena and **both spawn 2 heroes** with correct per-peer authority.
- Single-player is unaffected (all headless suites green; hub + arena boot clean).

### KNOWN MVP LIMITS (honest — the remaining co-op work)
- **Enemies are per-peer, not yet host-synced:** each client currently spawns its *own* enemy instances (so you both fight, but not the *same* mobs). Making enemies host-authoritative (one MultiplayerSpawner + Enemy MultiplayerSynchronizer, client AI gated off) is the next co-op task — it's scoped in the design spec but not built, because it's a larger refactor of `Encounter` that I didn't want to rush + can't fully verify without two machines.
- **Floor progression** is host-driven; cross-peer floor-advance sync rides on the same enemy/spawner plumbing.
- **Death in co-op** = respawn in place (no shared party-wipe→fall yet).
- **Feel/latency** (jitter, rubber-band, lag comp) can only be judged with two real machines — loopback can't show it.
- These are documented next steps, not crashes: the co-op foundation (connect / lobby / per-peer heroes / sync / friendly fire) works today.
