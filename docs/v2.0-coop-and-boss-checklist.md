Reach floor 5 (climb, or die-and-reclimb). Verified via GPU capture across all 3 phases.
- [ ] A **⚔ GUARDIAN ⚔** banner + a **THE ASHSPIRE GUARDIAN** name card + a top-screen **boss health bar** (3 segments = the 66/33 phase gates), with **boss music**.
- [ ] The boss is a **giant stone colossus** with glowing red eyes + a molten ember core + a red aura (offset from you so it reads as its own silhouette; the camera fits the whole arena).
- [ ] **P1** (100–66%): telegraphed ground-slam + rock pillars. **P2** (66–33%): enrage — summons adds + fires beams/rays. **P3** (33–0%): "ashfall" — meteor storm + a big convergence nuke + point-blank nova. Every attack is telegraphed (dodge the tell).

## 2. Co-op (2–4 players, friendly fire ON)
### How to run it
- **Same machine (test):** open the game twice. Instance A → **Host Co-op**. Instance B → type A's IP (`127.0.0.1` locally) → **Join**. Back on A → **Start Run**. Both drop into the tower.
- **With friends:** the host forwards/【shares】 their IP:port (`24565`); friends Join it. (LAN or a VPN like Hamachi/Tailscale for now — no matchmaking server yet.)
- **Headless smoke test** (proves connection + spawn): `python-tools/coop_smoketest.sh` (or run two console instances with `-- --server` and `-- --client 127.0.0.1`). Expected `[NET]` lines: host sees a peer (total=2), and **both** print `heroes=2`.

### What to check
- [ ] Both players appear in the arena; **each drives only their own hero** (the other moves via sync).
- [ ] **Friendly fire:** your spells can damage your teammate (and vice versa). The caster is never self-hit.
- [ ] Your class is the one you picked in the lobby.
- [ ] **Shared enemies (NEW):** you both fight the *same* mobs — a mob one player damages/kills is dead for both. Enemies are host-owned; a client's hits register on the host and sync back. Every hero can damage them; enemies chase whoever is nearest.
- [ ] **Shared floor progression (NEW):** clear the floor → the exit portal appears for both; **any** hero taking it advances the *whole party* to the next floor (the host rebuilds the same floor on every peer). The return-to-town portal ends the run for everyone.
- [ ] **Shared party wipe (NEW):** a hero who dies goes **DOWNED** (limp, immune, out of the fight) instead of respawning — enemies ignore them. You keep fighting; clearing the floor **revives** downed teammates on the next floor. If **everyone** goes down, the whole party **drops 2 floors** and revives together (Tower-of-God fall, shared).

### VERIFIED (headless, loopback — `python-tools/coop_smoketest.sh`)
- Two instances connect over 127.0.0.1; host sees the peer; both enter the arena with **2 heroes** (per-peer authority).
- **Shared enemies:** host + client both report the *same* enemy count, all `host_owned` (authority = host, peer 1), with **identical positions** — the client renders the host's synced enemies, not its own set.
- **Floor advance:** the host advances → **both** peers report the new floor (1→2), heroes persist.
- **SP untouched:** the full 36-suite headless sweep is green (incl. the new `slice_test_coop`, which locks that host + client build byte-identical enemies from the same data); hub + arena boot clean.

### KNOWN MVP LIMITS (honest — the remaining co-op work)
- **Enemy ATTACK visuals aren't replicated (the notable one):** the enemy/boss *bodies*, positions, and HP are synced and their damage lands correctly on every hero — but each enemy's **telegraph danger-circle, projectile, and AoE art render only on the host** (they're spawned as host-side effects, not networked). So on a **client**, you can be hit by an attack whose *tell* you didn't see. This is the top follow-up (route those spawns through a spawner too); until then the host has the fairest read of the fight.
- **Boss phase escalation + spectacle art show on the host only;** a client sees the guardian (synced body + HP bar) but not its beams/meteors/phase-tint. Damage still routes to all heroes.
- **Death spectacle** (corpse-fly / burst) and **destructible props** are per-peer/host-local — a client just sees enemies vanish and breaks its own copy of cover. Cosmetic.
- **Progression is host-authoritative:** the host owns `climber.json` (running the smoke test banks the host's advances to the real save). Conquering / returning ends the co-op session for everyone (clients bounce home).
- **Feel/latency** (jitter, rubber-band, lag comp) can only be judged with two real machines — loopback can't show it.
- These are documented next steps, not crashes: the shared fight (same enemies / shared floor progression / shared party wipe / friendly fire) works today over loopback.
