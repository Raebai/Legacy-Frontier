# Legacy Frontier — v0.0 Test Checklist

This is the manual test that proves v0.0 still works. Run it whenever you change anything in the dialogue / persistence / input layer, and before tagging a release. The pass criteria below are the **shipped definition** of v0.0.

The whole loop should be runnable end-to-end in **under 5 minutes** with no surprises.

---

## Prerequisites

- Ollama is running (system tray icon visible) and has `llama3.2:3b` pulled.
  - Quick check: `Invoke-WebRequest http://127.0.0.1:11434/api/tags -UseBasicParsing -TimeoutSec 3` should return HTTP 200 with `llama3.2:3b` in the list.
- Godot 4.6.2 stable available at `godot-engine/Godot_v4.6.2-stable_win64.exe`.
- Optional: delete `%APPDATA%\Godot\app_userdata\Legacy Frontier\npc_memory\raebai.json` to start with a clean memory.

## Section C — Whisper dialogue (LLM, history, persistence)

Run with a **fresh memory file** (delete `raebai.json` first if present). This section tests the magic moment.

| # | Step | Expected |
|---|---|---|
| C1 | Walk near Raebai, press **E** | Bottom input bar slides up with placeholder *"Whisper to Raebai — Enter to send, Esc to leave"*. Player movement is frozen. **No callback line** (no prior history) |
| C2 | Type *"hello"* → Enter | A *"you said: hello"* line appears above the input bar. Raebai's bubble shows animated dots, then his reply lands within ~3 s |
| C3 | Type *"my name is Raaed and I'm heading to Coldrose"* → Enter | Raebai's reply references either the name, the destination, or both |
| C4 | Send 1–2 follow-up messages | Raebai stays in character, doesn't repeat earlier questions, replies are 1–3 sentences |
| C5 | Type *"bye"* → Enter | Input bar **closes immediately**, player can move again. Raebai's parting line lands on his bubble within ~3 s and ideally references something specific (Raaed / Coldrose) |
| C6 | Verify on disk: `%APPDATA%\Godot\app_userdata\Legacy Frontier\npc_memory\raebai.json` exists, contains your messages and Raebai's replies | File is non-empty, valid JSON, includes the player turns from C2–C5 |
| C7 | Close Godot completely (window X, not just stop) | Godot exits cleanly, no error popups |
| C8 | Reopen project, press F5, walk back to Raebai, press **E** | Bottom input bar appears AND Raebai's bubble shows a callback line that **references something specific from the prior session** (your name, Coldrose, etc.) |
| C9 | Ask *"do you remember me?"* or *"what was my name?"* | Raebai's reply uses your name and/or references prior topics |
| C10 | Press **Esc** | Input bar closes, player can walk again |

**Pass criteria for C:** all ten rows green. C8 + C9 are the **magic moment** — if those two fail, v0.0 is broken.

## Known limitations (NOT failures)

These are by design for v0.0 and **don't fail the checklist**:

- Only one NPC exists (Raebai). Broadcast mode in D goes into the void — ambient NPC reactions land in v0.5 per D-031.
- NPCs cannot voluntarily end a conversation. Player-initiated farewell only. Per D-034 / D-037.
- NPC stats (mood, trust, patience) exist as data but don't affect behaviour yet. Behavioural integration in v0.5.
- No memory consolidation — message history grows unbounded. Token budget watch starts when this NPC's history exceeds ~50 turns. Tier 2 work.
- No on-screen virtual joystick / touch UI. Input map is action-named (D-011 ready) but the touch surface itself isn't built. Mobile-deploy verification deferred.
- Speech bubbles fade after a fixed interval; no scrollback. Scrollback log is a v0.5 polish.
