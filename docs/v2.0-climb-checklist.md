## 1. Persistent climb (the big one)

### A. Resume
- [ ] First-ever tower entry starts on **Floor 1 / 5**.
- [ ] Clear floor 1, take the cyan **EXIT** portal → banner reads **Floor 2 / 5**.
- [ ] Quit (X) mid-climb, relaunch, re-enter the tower → you **resume on the floor you'd reached**, not floor 1.

### B. Fall (die = drop 2, stay in the tower)
- [ ] On floor 3+, let the hero die. You should **NOT** return to the hub.
- [ ] The floor rebuilds at **current − 2** (floor 3 → 1; floor 5 → 3), hero at **full HP**, repositioned to the start.
- [ ] Die again → the drop-2 repeats; falls accumulate (`climber.json` `falls` ticks up).
- [ ] **Feel check:** does the in-place respawn read clearly? Any lingering death-ragdoll weirdness on revive? (MVP revive = HP + reposition only; flag if the rig looks stuck and I'll add a full state reset.)

### C. Return to town
- [ ] Clear any **non-boss** floor → **two** portals appear: cyan **EXIT** (climb) + gold **RETURN TO TOWN**.
- [ ] Take RETURN → back in the hub. Re-enter → you resume on the **next** floor (banked, no refight).
- [ ] The boss floor (5) shows **only** the EXIT portal (clearing it conquers).

### D. Town clocks the climb (the moat)
- [ ] After a fall, return to town, talk to Raebai/Mirelle → the greeting **references the fall** (and the count after repeat falls).
- [ ] After a clean return → NPCs reference the floor you reached.
- [ ] After conquering (clear floor 5) → NPCs react to felling the guardian.

### E. Rank persists
- [ ] Grind kills to raise the rank title, quit, relaunch, re-enter → **rank title/tier persists** (no reset to Nameless). *(This is new — rank used to reset every launch.)*

### F. Conquer + re-climb
- [ ] Clear floor 5 → return to hub with the victory outcome.
- [ ] Re-enter → a **fresh floor-1 climb** (rank + highest-floor persist as bragging rights).
