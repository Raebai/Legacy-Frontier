# v2.0 Slice 0 — Playtest Checklist + GO/NO-GO

> The single question that matters: **is the core fun?**
> Numbers below (speeds, cooldowns) are current tuning values, not spec — if a row fails on *feel*, tune the constant in `scripts/combat/` and re-run the row.
>
> Branch: `v2.0-tower`. Run scene is `res://scenes/combat/Arena.tscn` (temporary for Slice 0 — restored to `Main.tscn` in Slice 1).

## Pre-conditions (automated — run before playtesting)

From the repo root:

```powershell
& "godot-engine/Godot_v4.6.2-stable_win64_console.exe" --headless --path godot-project --import
& "godot-engine/Godot_v4.6.2-stable_win64_console.exe" --headless --path godot-project --script tools/slice0_test_targeting.gd
```

- [ ] Headless import completes cleanly (boot banners/driver warnings are fine; no script errors).
- [ ] Targeting test prints exactly: `Slice0 targeting tests: all PASS`.

If either fails: stop. Do not playtest over a red build.

## A — Movement

Launch the game (F5). You spawn as the blue mage in an enclosed arena.

- [ ] WASD moves the hero smoothly in all 8 directions (no stutter, no drift after key release).
- [ ] Walls block movement on all 4 sides — no clipping out of the arena, no getting stuck sliding along a wall.
- [ ] Speed feels right (~210 px/s): fast enough to reposition, slow enough that enemies are a threat. _If it feels floaty or sluggish, tune `Hero.gd SPEED`._

## B — Dash

- [ ] Space dashes in the current movement direction (or facing, if standing still).
- [ ] Dash distance feels satisfying — a real burst, not a hop (620 px/s for 0.14 s ≈ 87 px).
- [ ] Cooldown (0.55 s) *reads*: you can feel when dash is ready again; spamming Space doesn't chain dashes.
- [ ] Dash is genuinely usable to dodge — you can slip past a chaser closing in, or out of a brute's contact range.

## C — Casting

- [ ] Left-click fires a spell — every click within fire rate produces a visible projectile.
- [ ] Auto-aim reliably targets the **nearest** enemy: with two enemies on opposite sides, the spell goes at the closer one.
- [ ] With no enemies alive, casting still does something sane (fires in a fallback direction, no crash, no error spam).
- [ ] Fire rate (0.35 s cooldown) feels right: holding/spam-clicking feels like a rhythm, not a machine gun and not molasses.
- [ ] Projectiles hit what they aim at — moving enemies get hit, not just stationary ones.
- [ ] Spells expire (1.4 s) instead of littering the arena forever.

## D — Enemies

Arena keeps ~5 enemies alive, respawning on a timer. Two archetypes spawn 50/50.

- [ ] **Chaser** (orange): visibly fast (140 px/s), dies quick (24 HP ≈ 2 hits), light contact damage (8).
- [ ] **Brute** (magenta): visibly slow (62 px/s), tanky (70 HP ≈ 4 hits), heavy contact damage (18).
- [ ] The two archetypes *read differently at a glance* — colour + speed alone tells you which is which before it reaches you.
- [ ] Chase works: enemies track the hero as you move, don't orbit or jitter in place, don't pile into walls.
- [ ] Contact hurts: touching an enemy damages the hero, HP visibly drops, and there's feedback (you know you got hit).
- [ ] Kills respawn: the arena never empties — there's always something to fight within a few seconds.

## E — Juice

- [ ] Kills feel **crunchy**: hit-stop freeze frame + screenshake land together on the killing blow.
- [ ] Hit feedback on non-lethal hits: hit-flash + knockback make each spell impact readable.
- [ ] Screenshake is satisfying, **not nauseating** — after 2 minutes of continuous fighting your eyes aren't tired. _If it is, reduce shake amounts / decay in `CombatCamera.gd` / `Juice.gd`._
- [ ] Hit-stop is a punctuation mark, not a lag spike — the game never feels frozen or broken.
- [ ] Juice is time-scale-safe: rapid kills in quick succession don't stack into a slideshow.

## F — The verdict (GO/NO-GO)

Play for at least 5 uninterrupted minutes. Then answer honestly:

- [ ] **Is it fun?** Did you fight one more enemy than you meant to?
- [ ] **Would you want to keep playing?** Did stopping feel like a choice or a relief?
- [ ] **Is a clip of this cool/shareable?** 15 seconds of dash-weave-cast-kill — would that read as a game on a feed?

**Verdict:**

- **GO** → Slice 0 proved. Proceed to plan Slice 1 (the Climb: run structure → one floor guardian → one-landing hub with Raebai reacting).
- **NO-GO** → iterate on feel *here* (cheap) before building any structure on top. Better to learn it now than after a hub is bolted on.

## Known non-goals (NOT failures)

Deliberately deferred to Slice 1+ — do not mark the playtest down for any of these:

- No hub (Arena is a temporary sandbox run scene; `Main.tscn` returns in Slice 1).
- No run structure (no floors, no progression between fights).
- No progression (no XP, loot, upgrades, or spell unlocks).
- No boss / floor guardian.
- No mobile touch UI (input is named-actions only per D-011, so the virtual-joystick layer slots in later without code changes).
- One class only (the mage) — additional classes are a later slice.
